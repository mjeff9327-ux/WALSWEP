**Mnemonic Hunter Architecture v2.0**

Purpose: a live crypto seed/search/recovery + auto-sweep engine. Scans filesystem vaults (MetaMask, Exodus, Phantom, Trust Wallet, Coinbase, Atomic, Electrum), hardware wallets (Trezor, Ledger), brain wallets (SHA256 dictionary), MPC share files (Shamir's Secret Sharing), and social/Argent wallets for recoverable seeds/keys. Derives addresses via BIP44 across 8 chains, checks live mainnet balances including ERC-20/TRC-20 tokens and smart contract existence, builds and broadcasts real raw transactions per chain, and auto-sweeps found funds (threshold: ≥$1). Telegram notifications, HMAC license key gating, and affiliate split support are built in.

**High-Level Components**
- **TUI (Textual):** Full-screen terminal UI with chain toggles, multiple scan modes, SEARCH button (runs all modes then infinite BIP39), Derive and Sweep panels, license screen, and real-time found/checked panels including LabPanel for all operations.
- **API Gateway:** FastAPI REST gateway for scan jobs, events, and license verification.
- **Scan Engine:** Pipelines mnemonics through derivation -> balance check -> token scan -> contract existence check -> event emission. Optional Argent wallet address derivation when EOA has funds.
- **Auto Sweep Bot:** Multi-chain withdraw bot with real transaction building via TransactionSigner, configurable min balance threshold ($1), destination wallet, and affiliate split.
- **Transaction Signer:** Builds and broadcasts real raw transactions for all 8 chains — EVM EIP-155 RLP (ETH, BNB, POLYGON), BTC/LTC UTXO with per-input script signing, SOL ed25519 with canonical message format, XRP canonically serialized binary blob, TRON TronGrid.
- **Vault Scanner:** Scans real filesystem paths for wallet files by name pattern + content scan (embedded mnemonics, hex keys, WIF keys). Uses combined regex alternation (single O(1) pattern) and ThreadPoolExecutor for parallel directory scans. Extended patterns for Argent wallet detection.
- **Vault Cracker:** Dictionary-attack decryption of MetaMask (PBKDF2-SHA256/SHA512 AES-GCM), Exodus (Scrypt SECO binary), Phantom (NaCl SecretBox), Trust Wallet (Web3 keystore V3). Multiprocessing via ProcessPoolExecutor, mmap-based password file loading, optional Hashcat GPU integration (auto-detected, subprocess mode with per-wallet hash formatting), and smart password rule generation (case variants + suffix mutations).
- **Brainwallet Scanner:** SHA256(passphrase) -> BIP39 entropy -> BIP44 derivation across all 8 chains with live balance check. Multiprocessing via ProcessPoolExecutor, mmap-based dictionary loading, SQLite rainbow cache (pre-computed SHA256 → BIP39 entropy mapping).
- **HW Wallet Interface:** Trezor/OneKey (trezorlib) and Ledger (ledgerblue+ledgereth) detection, per-chain BIP44 address derivation, ready for signing.
- **MPC Recovery:** Shamir's Secret Sharing over secp256k1 prime field (256-bit). Scans for JSON/.share/.sss/SLIP-0039 files, reconstructs secrets, converts to BIP39 mnemonics.
- **Argent/Social Wallet Scanner:** Derives Argent wallet addresses from seed owner address via CREATE2 parameters (v1); filesystem pattern scan for argent-* files; checks contract existence + live balance.
- **Sweep Orchestrator:** Routes all operations — vault scan, brainwallet scan, vault crack, MPC share scan, HW wallet detect, Argent/social scan, and per-chain sweep — all with live balance check and optional auto-broadcast (concurrent multi-chain balance checking).
- **Telegram Notifier:** Sends real-time Telegram alerts on FOUND events.
- **License Validator:** HMAC-based license key verification with Telegram notification fallback.
- **Event Bus:** Pub/sub for FOUND, SCAN_STARTED, SCAN_STOPPED, WITHDRAWAL_PROPOSAL, SWEEP_EXECUTED events.
- **Config Manager:** JSON-based config with auto_broadcast enabled by default.

**Interfaces & DI Points**
- INodeClient, IKeyStore, ITransactionSigner, IWebhookClient, ILicenseVerifier, ISolver, IWalletOperator

**Search/Recovery Modes**

| Mode | Source | Method |
|------|--------|--------|
| Random BIP39 | PRNG | generate_mnemonic() -> BIP44 -> balance check |
| Bulk seed file | seeds.txt | line-by-line solve -> BIP44 -> balance check |
| Vault scan | Filesystem | filename patterns + content scan (mnemonic/hex/WIF) |
| Vault crack | Encrypted files | PBKDF2/Scrypt dictionary attack + decryption |
| Brain wallet | Dictionary | SHA256(passphrase) -> BIP39 entropy -> BIP44 |
| Hardware wallet | USB/HID | Trezor/Ledger public key -> per-chain BIP44 |
| MPC share scan | Filesystem | Shamir reconstruction -> BIP39 mnemonic |
| Argent/social scan | Filesystem + on-chain | CREATE2 derivation + contract check + balance |

**Supported Chains (8) — All Live Mainnet**

| Chain | API | Derivation (bip-utils) | Signing |
|-------|-----|------------------------|---------|
| BTC | blockstream.info | Bip44Coins.BITCOIN | UTXO secp256k1 (coincurve) |

| LTC | blockcypher.com | Bip44Coins.LITECOIN | UTXO secp256k1 (coincurve) |
| SOL | solana RPC | Bip44Coins.SOLANA | ed25519 canonical message (PyNaCl) |
| BNB | bscscan.com | Bip44Coins.BINANCE_CHAIN | EIP-155 RLP (coincurve + keccak) |
| XRP | xrpscan.com | Bip44Coins.RIPPLE | Ed25519 canonical binary blob |
| TRON | trongrid.io | Bip44Coins.TRON | secp256k1 + TronGrid broadcast |
| POLYGON | polygonscan.com | Bip44Coins.POLYGON | EIP-155 RLP (coincurve + keccak) |

**Controls (TUI)**
| Key | Action |
|---|---|
| Space | Start/Stop scanning |
| 1-8 | Toggle BTC/ETH/LTC/SOL/BNB/XRP/TRON/POLYGON |
| DERIVE | Open Wallet Derivation panel (seed -> address + private key) |
| SWEEP | Open Sweep Orchestrator panel (all 11 operations — scan, crack, sweep, HW, MPC, Argent) |
| E | Export found wallets to exports/ |
| L | Load seeds from seeds.txt |
| Q | Quit |
